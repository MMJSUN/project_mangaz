# project_mangaz：動態網頁爬蟲實作 - マンガ図書館Z

使用 **Selenium** 實作的動態網頁爬蟲，自動爬取「マンガ図書館Z」（漫畫圖書館Z）上的漫畫《房子機械狗》，逐頁截取圖片並儲存至本機資料夾。

## 📂 專案結構

```text
project_mangaz/
│
├── 漫畫存放處/                              # 程式執行後存放漫畫圖片的資料夾（33 張 PNG）
├── assignment01_scraper.py                  # 模組化（def 函式）後的 Python 執行檔
├── Assignment01_動態爬蟲案例_mangaz_練習版.ipynb  # 課堂練習用 Jupyter Notebook
└── README.md                                # 本說明文件
```

## 🛠️ 環境需求

- Python 3.x
- Google Chrome 瀏覽器
- 套件：

```bash
pip install selenium
```

## 🚀 執行方式

```bash
python assignment01_scraper.py
```

程式會自動：

1. 建立 `漫畫存放處` 資料夾（若不存在）。
2. 啟動已設定反偵測的 Chrome WebDriver。
3. 開啟目標漫畫頁面，點擊「開始閱讀」→「すぐに読む」進入閱讀器。
4. 逐頁擷取可見圖片並儲存為 `manga_page_N.png`，直到找不到下一頁按鈕為止。
5. 顯示總共儲存的圖片張數並關閉瀏覽器。

可於 `assignment01_scraper.py` 頂部的「設定區」修改目標網址（`TARGET_URL`）、儲存資料夾名稱（`FOLDER_NAME`）與等待秒數。

## 📖 作業背景說明（原始作業要求）

在進行技術開發與資料爬取時，我們必須重視一個核心議題：「技術如何應用於實際工作與生活，以及如何平衡創作者權益？」

根據統計，許多盜版漫畫與小說網站擁有極高的瀏覽量。這衍生出一個嚴肅的問題：**身為技術人員或讀者，你贊同盜版侵蝕正版方應得的利益嗎？如果不認同，你會採取什麼行動來保護正版？**

為了探討這個議題，本次作業帶領大家認識一個誓言消滅盜版漫畫的日本網站——**「マンガ図書館Z」（漫畫圖書館Z）**。
該網站由知名漫畫家赤松健創立，其運作模式非常特別：**任何人都可以上傳擁有的盜版漫畫檔案至該平台，供使用者線上閱讀。而網站產生的廣告收益，將 100% 由原作家領取。** 這個機制不僅保存了絕版漫畫，更讓作家獲得應得的收益。
